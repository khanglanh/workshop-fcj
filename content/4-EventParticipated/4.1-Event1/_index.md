# Report: “AI-Driven Development Life Cycle: Reimagining Software Engineering”

### Event Objectives

- Introduce how AI is redefining the modern software development lifecycle
- Explain the role of generative AI across the entire SDLC
- Demonstrate how AI automates repetitive tasks, helping developers increase productivity and focus on creative, high-value work
- Provide hands-on demos of two AI tools: Amazon Q Developer and Kiro

### Speakers

- **Toan Huynh** – Instructor, presented SDLC concepts and Amazon Q Developer
- **My Nguyen** – Instructor, responsible for the Kiro platform demo
- **Diem My, Dai Truong, Dinh Nguyen** – Event coordinators

### Key Highlights

#### AI and the Transformation of the Software Development Life Cycle

- Generative AI automates “heavy lifting” tasks such as code analysis, code generation, documentation, and testing.
- Significantly accelerates application development and reduces time-to-market.
- Allows developers to focus more on problem solving, creativity, and architectural optimization rather than repetitive work.

#### Amazon Q Developer

- AI assistant integrated into IDEs (VS Code, Cloud9…).
- Supports developers across the entire SDLC: code generation, testing, documentation, architectural recommendations.
- Capable of auto-generating code, reviewing code, and suggesting technical solutions.
- Helps accelerate modernization, upgrades, and refactoring for existing applications.

#### Kiro – AI Platform for Software Development

- Kiro provides AI-driven suggestions, workflow automation, and improved development efficiency.
- Demo illustrated its ability to generate code, detect errors, and optimize processes in real time.

### What I Learned

#### AI-Era Software Design Mindset

- Modern SDLC is not only about writing code—it includes integrating AI from end to end.
- Developers should transition to an **AI-assisted working model**, focusing more on business logic and system architecture.
- AI helps increase agility, reduce risks, and improve overall product quality.

#### Process Automation

- AI automates requirement analysis, documentation, code generation, and test case creation.
- Simplifies CI/CD implementation using AI-driven agents.
- Reduces effort required for maintenance and troubleshooting.

#### AI Tools in the SDLC

- **Amazon Q Developer**: assists across multiple SDLC stages, accelerating development and modernization.
- **Kiro**: enhances intelligent code analysis and generation, suitable for both large teams and startups.
- **ROI measurement**: cost reduction + business agility.

### Application to Work

- Applying AI to reduce development time and improve code quality.
- Integrating Amazon Q Developer into pipelines for automatic code review and documentation generation.
- Using Kiro as an AI programming assistant to increase productivity when handling large codebases.
- Restructuring workflows toward an **AI-first development model**.

### Event Experience

Attending the **“AI-Driven Development Life Cycle: Reimagining Software Engineering”** workshop was an extremely valuable experience, giving me a comprehensive understanding of how modern applications and databases can be modernized using AI-driven approaches.

#### Key Takeaways

- AI does not replace developers—it amplifies their capabilities.
- The future of software engineering is strongly aligned with AI-driven workflows.
- Implementing AI effectively requires the right mindset, a structured roadmap, and practical experimentation.
