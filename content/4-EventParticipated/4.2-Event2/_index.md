# Report: “AI/ML/GenAI on AWS”

### Event Objectives

- Gain an overview of the AI/ML and GenAI ecosystem on AWS
- Learn how to build, train, and deploy ML models using Amazon SageMaker
- Understand Foundation Models and how to apply GenAI through Amazon Bedrock
- Practice Prompt Engineering and Retrieval-Augmented Generation (RAG)
- Learn through live demonstrations that can be applied directly to real-world projects

### Speakers

- **Dinh Le Hoang Anh** – Instructor
- **Lam Tuan Kiet** – Instructor
- **Doanh Hoang Hieu Nghi** – Instructor

### Key Highlights

#### Welcome & Introduction (8:30 – 9:00 AM)

- Participant registration and networking
- Overview of workshop objectives
- Ice-breaker activities to connect attendees
- Overview of the AI/ML landscape in Vietnam

#### AWS AI/ML Services Overview (9:00 – 10:30 AM)

- Overview of **Amazon SageMaker** – the end-to-end Machine Learning platform
- Steps in **data preparation** and data labeling
- Model training, hyperparameter tuning, and deployment
- **Integrated MLOps** capabilities for pipeline automation
- **Live Demo:** SageMaker Studio walkthrough – interface and workflow demonstration

#### Coffee Break (10:30 – 10:45 AM)

#### Generative AI with Amazon Bedrock (10:45 AM – 12:00 PM)

- Foundation Models: **Claude, Llama, Titan** – comparison and selection criteria
- **Prompt Engineering:** prompt techniques, chain-of-thought, few-shot learning
- **RAG (Retrieval-Augmented Generation):** architecture and Knowledge Base integration
- **Bedrock Agents:** multi-step workflows and tool integration
- **Guardrails:** ensuring safe output and content governance
- **Live Demo:** Building a GenAI chatbot using Amazon Bedrock – from configuration to deployment

### What I Learned

#### AI/ML Knowledge

- Understanding the ML end-to-end workflow, from data to deployment
- Operating model training and tuning with SageMaker
- Applying MLOps to optimize ML development pipelines in enterprises

#### GenAI Knowledge

- Differentiating Foundation Models based on use cases: reasoning, text quality, speed, etc.
- Improving output quality using Prompt Engineering techniques
- Understanding how RAG increases accuracy through private data integration
- Becoming familiar with Bedrock Agents for automated AI workflows
- Recognizing and applying Guardrails to secure GenAI applications

#### Hands-on Skills

- Using SageMaker Studio for real ML workflows
- Building a GenAI chatbot using Bedrock and RAG
- Applying an AI-first workflow model for internal projects

### Application to Work

- Ability to initiate ML and GenAI POCs within the company
- Confidence in building ML or GenAI pipelines for tasks such as classification, Q&A bots, or enhanced search
- Applying Prompt Engineering and RAG to products requiring internal data
- Increasing programming and analysis productivity with GenAI tools

### Event Experience

Attending the **AI/ML/GenAI on AWS** workshop helped me gain deeper insights into modern AI technologies, from traditional Machine Learning to Generative AI.

#### Learning from AWS experts

- Speakers shared practical insights about SageMaker, Bedrock, and GenAI trends
- Examples and live demos made it easier to visualize concepts and apply them in real projects

#### Hands-on technical experience

- Observing SageMaker Studio in action clarified the ML workflow
- Building a GenAI chatbot through Bedrock demos helped me understand key components such as models, prompts, RAG, and guardrails

#### Utilizing modern tools

- I realized how AWS provides a complete toolset for building end-to-end AI systems
- Bedrock significantly reduces the time required to implement GenAI for enterprises

#### Networking and collaboration

- Networking activities created opportunities to learn from other engineers
- Gained deeper awareness of the rapidly growing AI/ML landscape in Vietnam

#### Key Takeaways

- ML and GenAI are two essential pillars of future technology
- AI-first thinking and integrating AI into workflows greatly enhance productivity
- RAG and Prompt Engineering are must-have skills for anyone working with practical GenAI systems
