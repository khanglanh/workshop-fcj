# Report: “DevOps on AWS”

### Event Objectives

- Provide comprehensive knowledge of DevOps and how to apply it on AWS
- Understand the DevOps mindset, culture, and core principles
- Gain hands-on experience building CI/CD pipelines with AWS services
- Master Infrastructure as Code (IaC) using CloudFormation and CDK
- Learn container services, system monitoring, and modern DevOps best practices

---

- **Dinh Le Hoang Anh** – Instructor
- **Van Hoang Kha** – Instructor
- **Nguyen Khanh Phuc Thinh** – Instructor

---

### **Welcome & DevOps Mindset (8:30 – 9:00 AM)**

- Recap of the previous AI/ML session
- Introduction to **DevOps culture and mindset**
- Benefits of DevOps and key metrics:
  - DORA Metrics
  - MTTR (Mean Time to Recovery)
  - Deployment Frequency

### **AWS DevOps Services – CI/CD Pipeline (9:00 – 10:30 AM)**

- **Deployment** with AWS CodeDeploy:
  - Blue/Green
  - Canary
  - Rolling updates
- **Orchestration** via AWS CodePipeline
- **Live Demo:** End-to-end CI/CD pipeline

### What I Learned

#### **DevOps Mindset**

- DevOps mindset accelerates development speed and improves product quality
- Understanding the importance of collaboration, automation, and measurement
- Familiarity with DevOps performance indicators (DORA)

---

#### **CI/CD Techniques**

- Designing Git workflows suitable for team size and structure
- Automating Build – Test – Deploy using CodeCommit, CodeBuild, CodeDeploy, and CodePipeline
- Selecting appropriate deployment strategies (Blue/Green, Canary, Rolling)

---

#### **Infrastructure as Code**

- Writing CloudFormation templates and automating infrastructure deployment
- Using CDK to define infrastructure using familiar programming languages
- Optimizing IaC with reusable constructs and best practices

---

#### **Containerization & Microservices**

- Understanding container architecture and microservices design
- Comparing ECS, EKS, and App Runner to choose the right solution
- Pushing, scanning, and managing container images in Amazon ECR

---

#### **Monitoring & Observability**

- Implementing comprehensive monitoring with CloudWatch
- Using X-Ray for request tracing and performance analysis
- Designing effective alerting and on-call processes

---

### Application to Work

- Building automated CI/CD pipelines for projects
- Applying IaC for transparent and reusable infrastructure management
- Choosing suitable container technologies based on project needs
- Improving troubleshooting time through observability systems
- Implementing DevOps best practices in real-world operations

---

### Event Experience

#### **Learning from AWS Experts**

- Instructors provided practical insights into modern DevOps
- Detailed demos helped me clearly understand real-world DevOps workflows

#### **Hands-on Technical Experience**

- Observing the entire CI/CD pipeline on AWS
- Gaining familiarity with IaC and container orchestration through real examples

#### **Using AWS DevOps Tools**

- Seeing how AWS offers a complete toolset for DevOps end-to-end
- Learning how to evaluate and choose the right tool for each project

#### **Key Takeaways**

- DevOps is not just a toolset—it is a **culture**
- Increased automation leads to lower risks and faster delivery
- Observability and incident management are foundational for modern operations
