During my internship at AWS from September 8, 2025 to December 9, 2025, I had the opportunity to learn, practice, and apply the knowledge I acquired at school to a real working environment. I participated in and developed the Teaching Center Management System project on the AWS Serverless platform, focusing on two main components: academic management — including course management, class management, enrollment using enrollKey, document management on S3, Excel import; and authentication/authorization — using Amazon Cognito, invite/redeem, Google SSO, and profile management.

My key responsibilities included designing the overall architecture and the architecture of the infrastructure services used; writing Infrastructure as Code templates using AWS SAM/CloudFormation; developing AWS Lambda functions for both academic and authentication modules; integrating API Gateway, DynamoDB, S3, Cognito; configuring CloudFront, Route 53, and WAF for the frontend; setting up a CI/CD pipeline with CodePipeline and CodeBuild; monitoring and alerting with CloudWatch Logs/Alarms and SNS. In my Full-Stack role, I implemented features for the STUDENT and TEACHER roles, which helped me improve my programming and data-processing skills, as well as gain more experience using AWS services to develop a production-ready project.

Regarding my work ethic, I always strive to complete assigned tasks effectively and actively communicate with team members to enhance project efficiency.
